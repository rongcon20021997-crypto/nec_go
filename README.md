# NEC GO | CCG-GROUP

Demo ứng dụng NEC GO phiên bản Trắng Vàng (White & Champagne Gold Edition).

## Cấu trúc dự án
- `index.html`: Giao diện chính của ứng dụng web tĩnh (được tối ưu để tự động triển khai lên Vercel).
- `NEC_GO_CCG_GROUP_Demo_Trang_Vang.html`: File demo gốc.
- `vercel.json`: Cấu hình routing cho Vercel.

## Triển khai lên Vercel
1. Đăng nhập vào [Vercel](https://vercel.com).
2. Chọn **Add New Project** -> **Import Git Repository** (`nec_go`).
3. Chọn **Deploy** (không cần cấu hình build command, Vercel sẽ tự động deploy dạng Static HTML).
